# QuickNotes

QuickNotes is a simple web-based note-taking application built using HTML, CSS and JavaScript.

## Features

- Add notes
- Choose a category for each note
- Display the date and time a note was created
- Search notes
- Delete individual notes
- Delete all notes
- Validate empty notes
- Validate the 200-character limit
- Save notes using localStorage
- Restore notes when the page is refreshed
- Responsive layout for smaller screens

## Categories

The application supports three categories:

- Personal
- Work
- Study

Each category has its own visual indicator.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

## How to Use

1. Enter a note in the text box.
2. Select a category.
3. Click **Add Note**.
4. Use the search box to find notes.
5. Click **Delete** to remove an individual note.
6. Click **Clear all** to remove all notes after confirmation.

## Validation

The application displays an error when:

- The note is empty or contains only spaces.
- The note contains more than 200 characters.

## Persistence

Notes are stored in the browser's localStorage. This means notes remain available after refreshing the page.
